先举一个例子
首先，这是一段代码，由C语言编写
```c
#include <stdio.h>

int main() {

    printf("Hello, World!\n");

    return 0;

}
```

逐行解释一下这段代码

```
#include <stdio.h>
```

预处理指令：引入标准输入输出头文件，`printf` 函数就在这个头文件里声明。

```
int main() {
```

`main` 是C程序入口函数，程序从这里开始执行；`int` 表示这个函数返回整型值。

```
    printf("Hello, World!\n");
```

调用标准库函数，向控制台输出字符串 `Hello, World!`，`\n` 是换行。

```
    return 0;
```

main函数返回0，代表程序正常结束，返回给操作系统。

```
}
```

标记main函数代码块结束。

### C源码 → 可执行文件 4个阶段

1. **预处理（preprocess）** 展开`#include`、宏替换、删除注释，生成`.i`文件（纯C文本）。
2. **编译（compile）** 把预处理后的C代码翻译成汇编代码，生成`.s`汇编文件。
3. **汇编（assemble）** 汇编器把汇编指令翻译成机器码（二进制），生成`.o`目标文件，里面只有本文件的机器指令，符号地址还没填好。
4. **链接（link）** 链接器把目标文件 + 依赖的库文件（比如printf所在的C标准库）合并，解析符号、修正地址，最终生成操作系统可以直接运行的可执行程序（Windows `.exe`，Linux ELF）。

# 什么是头文件

头文件（`.h`）本质是**声明的集合**，不存放函数完整实现代码，只放函数声明、宏定义、类型定义、结构体定义。 作用：告诉编译器 “有这个函数 / 变量，参数是什么、返回值是什么”，让编译阶段不报错；函数真正的实现代码在库文件（`.lib`/`.so`）里，等到链接阶段才合并进来。 `#include` 的本质：**把头文件里的文本原样复制粘贴到当前源码位置**。

# stdio.h

stdio = standard input output，**标准输入输出头文件**。 里面主要声明：

- 函数：`printf`、`scanf`、`putchar`、`getchar`、`fopen`、`fread`、`fclose` 等输入输出函数
- 宏：`EOF`、`NULL`
- 类型：`FILE`（文件结构体类型）

> 注意：stdio.h 里面**没有 printf 的实现代码**，printf 的实现放在 C 标准库中，链接的时候才去找。

简单一句话： 写 `printf` 时，编译器靠 `stdio.h` 知道 `printf` 的格式；链接器去标准库里拿 `printf` 的二进制实现。

### .h 头文件

- 后缀：`.h`
- 存放：**声明**（函数声明、宏、typedef、结构体、枚举）
- 没有：函数实现代码（一般不写函数体）
- 用途：给别的 `.c` 文件引用，告诉编译器接口长什么样
- 引入方式：`#include xxx.h`，文本复制
- 不会单独编译成 `.o`
- 原则：可以被多次包含（一般配合头文件保护宏）

### .c 源文件

- 后缀：`.c`
- 存放：**实现**（函数体、变量定义）
- 用途：程序逻辑主体
- 会单独经过预处理→编译→汇编，生成 `.o` 目标文件
- 可以 `#include` 头文件来拿到声明
- 一个 `.c` 对应一个编译单元

### 一句话对比

`.h` = 说明书（告诉别人怎么调用） `.c` = 真正干活的代码（功能实现）

### 简单例子

a.h（声明）

```
void hello();
```

a.c（实现）

```
#include "a.h"
void hello(){
    printf("hi");
}
```

main.c（使用）

```
#include "a.h"
int main(){
    hello();
    return 0;
}
```

### 容易踩坑点

1. 不要在 `.h` 里写变量定义、函数实现，容易多重定义报错
2. `#include` 只是文本粘贴，不是导入模块
3. 链接阶段才把各个 `.o` 和库拼在一起
