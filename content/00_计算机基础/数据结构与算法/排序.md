# 0 冒泡排序

```c
// 冒泡排序 升序

void bubbleSort(int a[], int n){

    for(int i = 0; i < n - 1; i++){

        for(int j = i + 1; j < n; j++){

            if(a[j] < a[j + 1]){

                int temp = a[j];

                a[j] = a[j + 1];

                a[j + 1] = temp;

            }

        }

    }

}
```


# 1 选择排序

**基本思想：** 在一轮排序中，我们从未排序区域找出最小的元素，将它放到未排序区域的最前面，通过不断重复这个过程，整个数组最终会变成有序的

```c
// 选择排序 升序

void selectionSort(int a[], int n){

    for(int i = 0; i < n - 1; i++){

        int minId = i;

        for(int j = i + 1; j < n; j++){

            if(a[j] < a[minId]){

                minId = j;

            }

        }

        if(minId != i){

            int temp = a[i];

            a[i] = a[minId];

            a[minId] = temp;

        }

    }

}
```
