> 根据题目分析得，至少有两个人对某道题目解决方案是确定的，那么这道题目就能实现
> 
> 可以两层循环，外层循环为题目总数n，内存循环三次表示三个人分别发表意见，内层循环结束后，计算下每次输入和，如果大于1，那么能解决的题目数量计数器就加一
> 

```c
#include <stdio.h>
int main(){

    int n;
    scanf("%d", &n);
    
    int count = 0;

    for(int i = 0; i < n; i++){

        int flag = 0;

        for(int j = 0; j < 3; j++){

            int x;

            scanf("%d", &x);

            if(x == 1){

                flag++;
            }
        }

        if(flag >= 2){
            count++;
        }

    }

    printf("%d", count);

    return 0;

}
```
